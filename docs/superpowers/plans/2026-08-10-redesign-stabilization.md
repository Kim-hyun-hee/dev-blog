### Task 4: Make post interactions lifecycle-safe

**Files:**
- Create: `src/scripts/postInteractions.ts`
- Modify: `src/pages/posts/[...slug]/index.astro`

**Interfaces:**
- Produces: `initPostInteractions(): () => void`.
- Cleanup closes the lightbox, restores body overflow, clears timers, and aborts event listeners.

- [ ] **Step 1: Extract an initializer with a single abort signal**

Start the module with:

```ts
let cleanupCurrent: (() => void) | undefined;

export function initPostInteractions(): () => void {
  cleanupCurrent?.();
  const controller = new AbortController();
  const { signal } = controller;
  const timers = new Set<number>();

  setupProgress({ signal });
  setupCodeCopy({ signal, timers });
  const closeLightboxImmediately = setupLightbox({ signal });

  const cleanup = () => {
    controller.abort();
    timers.forEach(window.clearTimeout);
    timers.clear();
    closeLightboxImmediately();
  };
  cleanupCurrent = cleanup;
  return cleanup;
}
```

Do not copy `addHeadingLinks`; it is intentionally removed.

- [ ] **Step 2: Preserve each behavior during extraction**

Move these existing blocks without changing user-facing behavior:

1. progress element creation and scroll calculation;
2. native Clipboard API copy button and 700 ms reset timer;
3. lightbox attributes, click/keyboard delegation, focus trap, touch pinch/pan, and body overflow restoration;
4. after-swap instant scroll reset.

The progress initializer must remove any old `.progress-container` before creating one, preventing duplicates.

- [ ] **Step 3: Replace the inline script with lifecycle hooks**

Use one module script in the post page:

```astro
<script>
  import { initPostInteractions } from "@/scripts/postInteractions";

  let cleanup = () => {};
  document.addEventListener("astro:page-load", () => {
    cleanup();
    cleanup = initPostInteractions();
  });
  document.addEventListener("astro:before-swap", () => cleanup());
  document.addEventListener("astro:after-swap", () =>
    window.scrollTo({ left: 0, top: 0, behavior: "instant" })
  );
</script>
```
